# Automation
This is an example of implementing a database using a node to allow the use of Selenium.

For this, we are going to start by creating a database in JS, because it's so simple. To register the credentials that will be on the site that will be created in HRML, CSS and JS. With this in mind we will start in the backend to recognize these credentials in the database created in node, so it will be executed in NPM to be even easier, the code compilations (Don't worry about pressing ctrl S because the npm package has already been configured to spam whether the change was made successfully or not and the code itself will save automatically).

Now, in the heavy backend part (Selenium and Electron), we will create an automation tool with Selenium, which is simpler than other tools out there. It will take the credentials stored in the automation tool and replace them on the website created as an example. Meanwhile, Electron will make the entire website behave like a '.desktop' app, further improving the efficiency of the site/app.
